# Changelog

## 0.1.0

First release.

- Several Google Workspace accounts in one window, including from different companies, each through the Google Cloud project you pick.
- Conversations, history, threads, sending with safe retries, and attachments up to 200 MB.
- System notifications and unread counters for every account, at an interval you choose, and a tray icon that keeps the app running with the window closed.
- In-app guide for setting up the Google Cloud project.
- English and Portuguese, light and dark themes.
- Packages for Linux (AppImage, .deb, .tar.gz), Windows (installer) and macOS (universal .dmg), not signed yet.
