# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussions about the work, and no harassment of any kind. Maintainers may edit or remove comments, issues and pull requests that break these rules, and block people who keep breaking them.

To report a problem privately, use a [private security advisory](https://github.com/Ruivalim/google-chat-client/security/advisories/new) or contact the maintainer through their GitHub profile.
